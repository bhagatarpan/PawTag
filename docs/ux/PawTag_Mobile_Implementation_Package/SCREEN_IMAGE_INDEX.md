# Individual Mobile Screen Image Index

There are **52 selected standalone screen images** in the ZIP. Each image is an independent portrait PNG, not a multi-screen board. The four extra intermediate variations (`order_history_screen.png`, `order_detail_screen.png`, `27_invoices_list.png`, `28_invoice_details.png`) are not included because the final manifest uses one selected image for each of those screens.

Generated mockups are concept references. Some contain invented names, values, dates, currency, statuses or navigation labels. OpenCode must use actual repository content and existing routes; the image is only guidance for composition and hierarchy. All navigation in implementation must follow current PawTag routes and its five account tabs.
