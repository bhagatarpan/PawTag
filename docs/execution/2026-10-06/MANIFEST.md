# Package Manifest

## Purpose

This archive is the complete PawTag autonomous execution package prepared from the current repository review, earlier verified plans, the web-first iOS/Android decision, the founder-provided DynamoDB migration plan, and the founder-provided Donation system plan.

## Top-level execution files

- `FOUNDER_GUIDE.md` — non-technical operating instructions.
- `00_READ_ME_FIRST.md` — agent/program entry point.
- `MASTER_EXECUTION_ROADMAP.md` — overall sequence.
- `01_SOURCE_OF_TRUTH_AND_PRECEDENCE.md` — conflict rules.
- `02_MASTER_DEPENDENCY_MAP.md` — dependency/parallel-work map.
- `03_EXTERNAL_OWNER_ACTIONS.md` — only the decisions/access AI cannot safely invent.
- `04_EXECUTION_STATUS_TEMPLATE.md` — evidence-based progress tracking.
- `05_CURRENT_STATE_AUDIT_SYNTHESIS.md` — verified current-risk synthesis.
- `SKILLS_MANIFEST.md` / `SKILLS_VALIDATION.md` — skill changes and validation.

## Execution directories

- `phases/` — 19 ordered implementation phase files, 00 through 18.
- `verification/` — payment/provider, email/invoice/notification, API, mobile device, DynamoDB, donation, and first-customer gates.
- `prompts/` — copy/paste agent prompts for execution, review, failure recovery, DynamoDB packets, and donation packets.
- `repo-overlay/` — updated root `AGENTS.md` plus the complete updated `skills/` directory.
- `reference-plans/` — prior plans retained for context only.
- `reference-inputs/` — founder-provided Donation and DynamoDB source planning documents.
